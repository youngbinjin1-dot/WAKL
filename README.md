# WAKL

나에게 맞는 산책 장소를 찾는 모바일 앱 미리보기입니다. 아이폰 16 비율의 화면에서 Google 지도와 조건별 검색을 제공합니다.

## 실행

1. `WAKL.html`을 내려받아 브라우저에서 엽니다.
2. 좌측 상단 설정 아이콘에서 본인의 Google Maps API 키를 입력합니다.
3. 지역을 검색하거나 지도를 이동한 뒤 우측 상단 새로고침 아이콘으로 산책 장소를 찾습니다.

Google 지도와 검색은 인터넷 연결이 필요합니다. 브라우저/키의 도메인 제한 때문에 로컬 파일에서 지도가 열리지 않으면 허용된 웹 주소 또는 로컬 웹 서버에서 실행해주세요.

## API 키

저장소에는 API 키를 포함하지 않습니다. 입력한 키는 현재 브라우저 탭의 세션 저장소에만 보관되며 지도·검색 요청을 위해 Google로 전송됩니다. Google Maps JavaScript API, Places API (New), Geocoding API를 활성화하고 프로젝트 결제 및 허용 웹 주소를 설정해야 합니다. API 사용료는 Google 계정 설정에 따릅니다.

## 기능

- 지역 검색과 지도 범위 내 장소 다시 찾기
- 반려견 동반, 인원, 카페, 분위기 선택
- 반려견 동반 불가가 확인된 장소 제외, 정보 미확인 후보는 상세에서 안내
- 분위기를 검색어에 반영하는 추천
- 위아래 드래그로 접고 펼치는 선택창
- 회갈색 발바닥 산책 표시와 아이보리 배경
- 코스 상세 및 Google 지도로 출발 지점 열기

## 데이터 안내

첫 화면의 다섯 경로는 UX 확인용 예시이며 실제 보행 경로가 아닙니다. 검색 후에는 Google 장소 검색 결과를 사용합니다. 분위기는 검색어 기반 추천이고 인원·주변 카페·반려견 규정이 확인되지 않은 후보도 포함될 수 있으므로 방문 전 현장 규정을 확인해주세요. 장소 검색 결과의 발바닥 표시는 위치 마커이며 실제 산책 경로 안내가 아닙니다.

## 수정 및 HTML 생성

`src/`의 HTML/CSS/JavaScript를 수정한 뒤 Node.js에서 실행합니다. 외부 패키지 설치는 필요하지 않습니다.

```sh
node build.cjs
```

`index.html`과 단일 파일 `WAKL.html`이 생성됩니다. API 키를 소스에 입력하거나 커밋하지 마세요.

지도 연동 일부는 Google LLC의 Apache 2.0 예제를 기반으로 수정했습니다. 관련 고지는 `NOTICE`에 포함했습니다.
